# 여덟째 칸 서버 리소스팩

마인크래프트 26.3 "여덟째 칸"(사람이 말이 되는 체스) 서버에 접속하면 자동으로 받는 리소스팩입니다. 따로 내려받아 설치할 필요가 없습니다.

- 팬이 만든 비공식 서버용 팩입니다. 공식 Minecraft 서비스가 아니며 Mojang, Microsoft 와 관계없습니다.
- 릴리스의 `HumanChess-pack.zip` 이 서버가 보내는 파일입니다(태그 `pack-<sha1 앞 12자리>`).
- 출처와 라이선스는 zip 안 `licenses/` 에 있습니다.
  - 배경 음악: Kevin MacLeod (incompetech.com), Creative Commons Attribution 4.0. 곡마다 제목과 고친 내용은 `licenses/CREDITS-music.txt`
  - 효과음: Kenney 의 소리 모음(CC0)과 그 밖의 CC0, CC BY 녹음을 잘라 다듬은 것. 사건마다 출처는 `licenses/CREDITS-sound.txt`
  - 맵 꾸밈 블록: ambientCG, Poly Haven 의 CC0 재료를 16x16 도트로 다시 그린 것과 Decorative Blocks(MIT) 모델. `licenses/CREDITS-decor.txt`
  - 기물 모델: PolyChess(MIT, Copyright (c) 2025 Phoenix), 겹치고 물들이고 조각으로 나눠 씀
  - 글꼴: Galmuri11(SIL OFL 1.1)으로 미리 그린 글귀 그림
  - 대사: 루이스 캐럴 "거울 나라의 앨리스"(1871, 퍼블릭 도메인) 원문에서 골라 직접 옮긴 42줄
  - 아이콘, 기물 그림, HUD 도트 그림과 셰이더는 이 서버가 직접 만든 것입니다. 바닐라 아이템 그림은 쓰지 않았습니다.
- 비상업용입니다. 후원, 유료 기능, 광고와 엮지 않습니다.
